# Meteo

Donne la météo de la plus part des villes mondiale et la qualité de l'air

- This plugin is an add-on for the [A.V.A.T.A.R](https://avatar-home-automation.github.io/docs) framework. 

 ## 🎯 Usage
Commandes :
- donne moi la météo(par defaut paris), il fait quel temps a new york
- donne moi la météo demain à marseille
- il fait quel temps aprés demain à pekin
- donne la météo sur 3 jours
- quel est la qualité de l'air

- plugin plug&play sans clé api

## Multi-room

The `Meteo` plugin is fully multi-room.

## Multi-language

The `Meteo` plugin relies solely on the system's available languages.
